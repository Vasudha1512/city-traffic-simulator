# 🚦 City Traffic Simulator: Smart Intersection Control

## 📌 Overview
City Traffic Simulator is an interactive web-based simulation that visualizes traffic flow at a city intersection. Users can control signals, adjust speed, and observe how vehicles behave in real time under different conditions.


## 💡 Concept
The core idea is to recreate the feeling of:

- Managing real city traffic  
- Controlling signal systems dynamically  
- Understanding congestion and flow  

As the user interacts:

- Traffic lights affect vehicle movement  
- Flow changes based on timing and control  
- Congestion builds or clears dynamically  

👉 It feels like controlling a real traffic junction, not just watching a simulation.


## 🎯 Features

### 🚦 Traffic Signal Control
- Manual signal toggle  
- Auto signal mode  
- Emergency override system  

### 🚗 Real-Time Simulation
- Live vehicle movement  
- Dynamic traffic flow  
- Wait time and car count tracking  

### ⚡ Adjustable Speed
- Control simulation speed  
- Observe slow vs fast traffic behavior  

### 🌧️ Environment Controls
- Rain mode toggle  
- Affects driving conditions  

### ✨ Animations
- Smooth vehicle motion  
- Signal light transitions  
- Dynamic intersection visuals  

### 📱 Mobile-Friendly Design
- Responsive layout  
- Touch-friendly controls  
- Clean UI interface  


## 🧩 How It Works
1. User enters the simulation  
2. Vehicles start moving automatically  
3. User controls traffic signals or enables auto mode  
4. Traffic flow changes based on decisions  
5. Metrics like wait time and cars update in real time  
6. User optimizes flow and reduces congestion
